# Code of conduct

rackscale follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work and not people, and keep technical
disagreement technical. Measurements settle arguments here; tone does not.

Report unacceptable behaviour privately to the maintainer, GitHub user
[AbiralShakya](https://github.com/AbiralShakya). Reports are handled confidentially.
